# OGAS
> aka Optional Goal, Action System

## Getting started
You can download last version from [releases](https://github.com/nevervoyage/OGAS/releases) as .rbxm file

## Why?
OGAS is Action system with optional GOAP (Goal-Oriented Action Planning) help.

This small framework provides you everything you need to make any action you want.

## How to learn?
Check out documentation in [docs](https://github.com/nevervoyage/OGAS/blob/main/docs/getting-started.md)!
